* Test Definitions
** Evidence selection
- *No new RT*: this is a literal correction to a release-only inspector with an
  established one-off verification boundary. Corpus correctness is already
  covered by the maintained prompt-pack regression tests. Another permanent
  hard-coded corpus test would duplicate that assertion rather than improve
  the incident evidence.

  release is not required to verify the inspector's exit status and diagnostics.
- The existing OT-78.1 - sensitive artefact rejection fixture is kept consistent
  with the corpus; the direct check below exercises the same process boundary.
